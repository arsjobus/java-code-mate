# Principles

## Purpose

Code Mate exists to help a person create software with a computer. It should not attempt to become a social platform, cloud workspace, content feed, or autonomous development environment.

## Local ownership

Source code belongs on the user's machine. The editor should work against ordinary files and directories rather than requiring proprietary project storage.

## Offline capability

Core editing, navigation, search, build, run, terminal, and version-control workflows should remain useful without an Internet connection.

## Explicit action

Important actions should be visible and understandable. The application should avoid doing things merely because it can.

## Human direction

Automation may assist the programmer, but the programmer remains the authority. AI-generated modifications should be proposed and reviewable before they are applied.

## Privacy

No telemetry should be required. Network access should be deliberate rather than ambient.

## Interoperability

Use ordinary files, standard tooling, Git, language servers, terminals, and documented formats wherever practical.

## Simplicity

A small understandable system is preferable to a large framework whose behavior becomes difficult to reason about.

## Attention

The editor should not compete for attention. There should be no news feed, trending extensions, social activity, recommendation loop, or gamification.

## Durability

Projects should remain usable if this editor disappears. Avoid proprietary lock-in.

## Philosophy

The editor is a workshop. It is not the product the user is meant to spend time inside.
